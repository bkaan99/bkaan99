## 👨‍💻 About me

I'm an electrical and electronics engineer who builds on both sides of the stack: hardware and embedded systems on one end, modern web applications and applied AI on the other. I enjoy turning an engineering problem into a working, maintainable product.

- 🌐 **Web:** production web apps and business tools with Next.js, React and TypeScript, from e-commerce to dashboards and AI-assisted messaging panels.
- 🧠 **AI / Computer Vision:** deep learning, image processing and medical AI, including model deployment with ONNX and TensorRT.
- ⚡ **Electronics:** multilayer and high-speed PCB design, BLDC driver circuits and power electronics. I'm also interested in avionics and model rocketry.
